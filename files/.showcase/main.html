What's inside

headline features

Stable GUID

Every document keeps its UUID through rename, move, even soft-delete. Links never rot.

Auto-versioned

Every save is a git commit. Threads auto-snapshot. Restore any past state of any document.

Threads on a quote

Select text, right-click, type a question. Anchored to that exact passage.

MCP-native

12+ tools your agent calls directly. Same surface as the UI. No translation layer.

HTML next to markdown

Drop an interactive dashboard into the same folder as a memo. Sandboxed iframe in DOCI's shell.

Self-host, VPN-private

One server, one VPN. No external SaaS. Your agents' output stays on your hardware.
