# Welcome to DOCI

This is an example document. Edit me, delete me, or use me as a template.

DOCI stores documents as plain markdown files under `files/` and tracks
their metadata (path, title, tags, version chain) in PostgreSQL. Every
mutation is committed to git, so the file history doubles as a version
log.

## Try it

- Edit this file in the UI.
- Open a thread on a selected passage.
- Use the inbox to dump rough notes that don't yet have a home.
