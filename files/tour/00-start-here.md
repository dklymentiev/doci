# Start here

This is the DOCI tour. Nine short pages, each shows a real feature with
a real example you can click. Total: about ten minutes.

## What DOCI actually does

You give an agent a job. The agent finishes, writes the result as a
markdown document in DOCI, and pastes the link in your chat:

```
Done. Report at http://docs.local/a1b2c3d4-...
```

You open the link. You read. You find a paragraph that looks off,
select the sentence, right-click, type a question. The agent picks up
the thread on the next turn and replies inside that same document.

That is the entire product. Everything else -- versions, inbox,
HTML rendering, search -- is in service of that single loop.
