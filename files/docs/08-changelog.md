# DOCI — Changelog

The canonical changelog lives at the repository root:
**[`../CHANGELOG.md`](../CHANGELOG.md)**.

That location is kept so dependabot, GitHub release notes, packagist,
and other tooling find it without configuration. This file exists only
so the `docs/0N-*.md` numbering stays gap-free per
[`09-doc-pipeline.md`](09-doc-pipeline.md).

DOCI follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and [Semantic Versioning](https://semver.org/spec/v2.0.0.html). The
release process — which sections to update, when to bump major vs
minor, the live-benchmark gate — is documented in
[`../RELEASING.md`](../RELEASING.md).
