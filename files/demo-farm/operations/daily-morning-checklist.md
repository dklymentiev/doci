# Daily morning checklist

Owner: rotates (Mike / Devon / seasonal lead) | Last review: 2026-05-01

Every morning, 5:30am, before the day plan. Takes ~45 minutes if
nothing is wrong, 90+ if something is.

## Livestock side (Devon or designate)

- [ ] Walk the dairy herd. Count: should be 18 + bull = 19 in
      pasture or barn. Note absences immediately.
- [ ] Check water troughs (3 in pasture, 2 in barn). Top up or call
      for tank refill if below 1/3.
- [ ] Visual mastitis check at first milking -- any abnormal teat or
      udder = pull aside, send sample.
- [ ] Bulk tank temp check: must be < 40°F. Log on tank sheet.
- [ ] Calf pens: count, check appetite at AM feed.
- [ ] Bull (leased): visual check, fence intact.

## Crop side (Pat or designate)

- [ ] Weather check: NWS 24h forecast, frost watch in shoulder
      seasons, blight humidity readings May-September. See
      [Blight watch](/demo-farm/crops/blight-watch-may) for current
      thresholds.
- [ ] Walk the four fields in rotation order. Look for: deer
      pressure, irrigation pooling/dry spots, lodged plants.
- [ ] Check the high tunnel: vents on if > 75°F forecast, off if
      frost.
- [ ] Irrigation pressure check at North-A drip header. Should read
      28-32 psi at the pump (see
      [pump failure post-mortem](/demo-farm/incidents/2026-04-12-irrigation-pump-failure)
      for why this is now on the checklist).
- [ ] CSA harvest priority list update on the whiteboard.

## Shared

- [ ] Read the previous shift's [handoff note](/demo-farm/people/shift-handoff-template).
      Acknowledge or escalate any pending items.
- [ ] Phone notifications: anything from suppliers, USDA, NOFA-NY,
      buyers? Skim, flag, defer.
- [ ] Coffee. Non-negotiable.

## What NOT to do during the checklist

- Don't multitask deliveries (suppliers come 9am+, leave them for
  later).
- Don't start any task that takes > 15 minutes during the round --
  finish the loop first, then act on findings.
- Don't skip steps "because nothing was wrong yesterday." The
  checklist is the way we make sure nothing _is_ wrong today.

## If something is wrong

| Severity | Response |
|---|---|
| Routine (broken hose, low water) | Fix it before 7am if possible, log in handoff if not. |
| Animal health concern | Pull aside, photograph, page Devon if not on shift. |
| Infrastructure failure (pump, fence, power) | Stop the round. Call Mike. File incident at end of day. |
| Suspected disease (mastitis, blight, etc.) | Sample / photograph BEFORE intervention. Open a thread in the relevant doc. |
