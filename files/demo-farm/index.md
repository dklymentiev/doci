# Hollow Creek Farm

Small certified-organic mixed farm in Tompkins County, NY (Finger Lakes
region). Run by Sarah and Mike Reeves. 47 acres total: 12 in
vegetables, 8 in pasture, 22 in hay, 5 in barn/yard/farmhouse.

| Quick facts | |
|---|---|
| Founded | 2017 |
| USDA Organic cert | NOFA-NY, since 2019 |
| Dairy herd | 18 Jerseys |
| Vegetable share members (CSA) | 84 (2026 season) |
| Full-time team | Sarah, Mike, Pat (vegetables), Devon (livestock) |
| Seasonal | 3–5 workers, May–October |
